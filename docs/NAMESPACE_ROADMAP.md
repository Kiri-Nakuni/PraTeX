## 途中で決めたこと

| | |
|---|---|
| **空白・行末は runaway** | 名前空間の名前は一続きでなければならない。catcode 5/9/10 と行の終わり |
| **`\namespacechar` の既定は −1** | 印字しない。名前空間を使わない文書では見えない |
| **`\csname` 以外が続けば誤り** | `\namespace foo\relax` は「Missing \csname」 |
| **入れ子は許す** | 二つの `\namespace` は同じ `\csname` を奪い合わない——括弧のように入れ子になるだけ |

## 途中で撤回したこと

**「入れ子は誤り」を一度入れて、撤回した。**

```tex
\namespace \namespace hoge\csname fuga\endcsname \csname bar\endcsname
```

内側は最初の `\csname…\endcsname` を消費して `*hoge\fuga` を作り、
それが展開されて**外側の名前空間名の文字になる。**
外側は自分の `\csname` を別に持つので、**競合しない。**

禁じれば非対称が生まれる——`\namespace \ns\csname bar\endcsname` は
`\ns` が global のマクロなら通るのに、名前空間つきのマクロだと通らない。

> **名前空間名は展開で作られた文字列にすぎない。**

## 分かったこと

**`\ifx` は意味を比べる。** `*foo\aa` と `\aa` の中身が同じなら等しいと言う——
これは TeX82 のとおりで正しい。**同一性の判定は `\ifx` の仕事ではない。**

## 残り

### Phase 6 でやったこと（`\usingnamespace`）

```tex
\usingnamespace lib
\greet          % *lib\greet に解決される
```

| | |
|---|---|
| **探索順** | **global が先。** 定義があればそれ。無ければ使用宣言の追加順 |
| **保存スタックを通す** | 群を出れば一覧が戻る。`\global` も効く |
| **`\csname` も参加する** | だから `\relax` 化は起きない——§6 の「既知の危険」は実態より強かった |
| **一覧が空なら何もしない** | 素の TeX82 とまったく同じ道。**使わない機能は費用を持たない** |

#### 途中で見つけた二つの誤り

1. **一文字の制御綴が探索から漏れていた。**
   `to_token` は `\x` を `Single(c)` へ直に落としており、`lookup` を通っていなかった
2. **`*lib\~` と `*lib~` が鍵で衝突していた。**
   どちらも名前が一文字の `~` になる。鍵に「活性か」を足した
